# Wonder Psychometric Instrument v2.1

## Objective
Wonder's first instrument is optimized for **felt accuracy, useful differentiation, and relationship relevance**. It is not presented as a validated clinical or diagnostic test.

The instrument estimates a latent person model first. Archetypes are narrative interpretations of that model. Matching uses the underlying dimensions, not archetype labels.

## Current bank
50 items across six experiential sections:
- Instinct
- Self
- Values
- Relationships
- Under pressure
- Shadow

Item formats include contextual forced choice, 1–7 scales, multi-select, and value ranking. Forced choices are used only when the alternatives reveal a meaningful tradeoff; false binaries are avoided.

## Measurement domains
### Cognitive
Systemizing, context sensitivity, ambiguity tolerance, decisiveness.

### Temperament
Novelty orientation, social initiation, emotional intensity, structure preference.

### Relationship
Autonomy need, closeness need, reassurance sensitivity, vulnerability openness, conflict directness, repair orientation, reciprocity sensitivity, baseline trust.

### Values
Family, achievement, meaning, freedom, stability, knowledge, service, influence, beauty, loyalty.

### Identity
Recognition, competence, distinctiveness, belonging.

### Stress
Control, withdrawal, accommodation, intellectualization.

## User experience target
The production onboarding should not necessarily show all 50 items. Target 28–36 items for most users.

1. Core pass: ~24 high-information questions spanning every domain.
2. Contradiction pass: 4–8 questions selected where answers conflict or evidence is weak.
3. Precision pass: 2–4 questions selected around dimensions most consequential for matching or the user's emerging archetype profile.

A user should feel that later questions become more personally relevant, not that they are completing a generic personality inventory.

## Adaptive selection heuristic
Until sufficient empirical data exists, select follow-ups using:
1. lowest evidence coverage on consequential dimensions;
2. contradictions (e.g. high autonomy + high reassurance, high closeness + high withdrawal, high competence identity + high control under stress);
3. near-ties between primary archetypes;
4. dimensions that materially affect matching (values, closeness/autonomy, repair/conflict, trust/reciprocity).

Later replace hand-tuned information weights with observed item discrimination and outcome prediction.

## Resonance rules
A Mirror statement should require converging evidence from multiple items whenever possible. Avoid presenting a single response as a settled trait.

Prefer language such as:
- “You appear to…”
- “A pattern Wonder noticed…”
- “This may become more pronounced when…”
- “Wonder is less certain about…”

Do not use clinical labels or imply diagnosis.

## Archetype output
Return:
- primary archetype;
- secondary archetype;
- confidence / separation from alternatives;
- 3–5 high-confidence traits;
- 1–2 meaningful tensions or contradictions;
- dimensions Wonder is still uncertain about.

Archetypes are deliberately non-exclusive. Two people with the same primary archetype can have materially different relationship profiles.

## Matching principle
Hard constraints are evaluated first. Compatibility is then estimated from underlying dimensions. Archetype similarity is not itself a compatibility criterion.

Initial compatibility hypothesis:
- 35% values
- 30% relationship needs
- 25% conflict / repair
- 10% cognitive interaction

These weights are provisional and should eventually be calibrated against outcomes.

## Feedback loop
Collect after the Mirror:
- overall accuracy rating;
- which statements felt most accurate;
- which felt wrong;
- optional correction in the user's own words.

Collect after introductions/dates:
- desire to continue;
- attraction;
- conversational ease;
- feeling understood;
- emotional safety;
- values fit;
- conflict/friction if applicable.

These become the empirical basis for pruning weak questions, changing weights, adding constructs, and eventually validating the instrument.

## Product standard
Every item must answer: **What inference does this produce, how does it differ from adjacent constructs, and how could it eventually improve an introduction?**

If there is no good answer, the item does not belong in Wonder.
